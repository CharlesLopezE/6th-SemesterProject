# 6th-SemesterProject
A Web Application that helps prevent Jet Lag for travelers.

**User Authentication**

**Users can:**

Create an account
- Log in securely
- Log out
- Stay authenticated using Supabase sessions

**Includes:**
- Sign-up page
- Login page
- Email/password authentication
- Profile icon with user initial

**Personalized Sleep Schedule Generator**

**Travelers can enter:**
- Traveler email
- Flight number
- Gate number
- Departure city
- Arrival city
- Departure time

**The system then:**
- Generates a jet lag reduction sleep schedule
- Displays the schedule on the homepage

**Trip Creation & Management**

**Users can:** 
Create trips, Save trips to Supabase, and View trips in the UI
**Trip information includes:**
Flight number, Gate number, Departure city, Destination city, and Departure time

**My Trips Dashboard**

**The My Trips page allows travelers to:**
- View saved trips
- Switch between:
- My Trips
- My Activity

**UI Features:**
- Dynamic tab switching
- Responsive trip cards
- Organized traveler dashboard

**Saved Schedules Page**

**Users can:**
- Store generated sleep schedules
- View previously saved schedules
- Access schedules during travel

**Activity Tracking**

**The My Activity section can display:**
- Recently created trips
- Generated schedules
- Traveler actions/history

**Settings System**

**Current settings feature:**
- Theme switching
- Dark mode
- Light mode

**Uses:**
- Local storage to remember preferences

**Informational Pop-up Windows**

**Popup modals include:**
- About, Contact Us, and Settings

**About explains:**
- Purpose of No JetLag
- Sleep optimization
- Travel assistance features

**Responsive Modern UI**

**The application includes:**
- Glassmorphism design
- Gradient backgrounds
- Modern navigation
- Interactive hover effects
- Animated modal windows
